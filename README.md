📚 BookStore API

A clean and well-structured ASP.NET Core Web API project built to practice backend fundamentals and demonstrate a real-world API architecture using Entity Framework Core, SQL Server, Dependency Injection, and Swagger.

This project is part of my backend learning journey and focuses on writing clean, maintainable, and scalable API code following best practices.

🚀 Features

- RESTful API built with ASP.NET Core
- CRUD operations for Books
- SQL Server database with Entity Framework Core
- Database migrations using EF Core
- Pagination support
- Global exception handling with custom middleware
- Dependency Injection with service layer
- Swagger UI for API documentation and testing
- Data validation using DTOs and Data Annotations
- Clean project structure (Controllers, Services, Models, DTOs, Data, Middleware)
- Proper HTTP status code handling
- Asynchronous programming (async / await)

🧱 Technologies Used

- ASP.NET Core Web API 
- Entity Framework Core
- SQL Server (LocalDB)
- EF Core Migrations
- Swagger / OpenAPI
- C#
